# QBank API

Question bank management and online examination assessment service.

## Features
- Question repository management with categorized tagging (Subject, Topic, Difficulty).
- Multiple-choice and descriptive question formatting.
- Dynamic test generation and answer evaluation.

## Tech Stack
- Java 21 LTS
- Spring Boot, Spring Data JPA
- MySQL 8.0
- Maven Wrapper

## Running
```bash
./mvnw clean compile
./mvnw spring-boot:run
```
